香港初級大人說明書（原名：香港大人說明書；HKAdultManual）

1. 簡介

「香港初級大人說明書」（原名「香港大人說明書」，下稱「本服務」）包括 iOS App、公開網站及可安裝的 PWA（網頁 App）。本私隱政策說明本服務如何處理用戶資料。名稱更改不影響本服務的營運者、帳戶、訂閱、既有內容或本政策下的權利與責任。

本App的「小貼士」內容基於廣泛公開來源；「大學問」提供基於多重來源的個人成長內容。

本App由 Sunny Lai 開發及營運。如有任何私隱相關疑問，請電郵至 sunnyyylai@icloud.com。

2. 我們處理的資料

公開閱讀、在目前裝置收藏文章及使用每日免費閱讀額，毋須提供電郵、電話或真實姓名；服務可先建立一個隨機 Firebase 用戶識別碼（UID），把相關紀錄與目前訪客身份連結。發帖、留言、提問、回答、使用聊天室、舉報或上載相片／錄音等公開互動，必須先註冊帳戶並完成電郵驗證。PWA 可讓你用 Email Link 把現有訪客身份升級為電郵帳戶，升級會保留原有 UID；我們不會把兩個既有 UID 自動合併。

  • 帳戶識別資料：隨機 Firebase UID、帳戶角色、驗證狀態、已驗證電郵（當你註冊或升級帳戶），以及因違反社群守則而設定的社群停用狀態。
  • 用戶提供的個人資料：顯示名稱、簡介、所選頭像圖案／顏色，以及你主動上載的自訂個人頭像或個人檔案橫額。請勿使用真實姓名或在公開個人資料圖片／簡介披露敏感資料。
  • 用戶內容（UGC）：社群貼文、留言、聊天室文字及語音訊息、反應、舉報、讀者點題、寫手申請、文章草稿以外的投稿內容及審核紀錄。
  • 用戶選取的相片／影片類別資料：當用戶主動在社群貼文、留言、對話、讀者點題或投稿功能選取並提交媒體時，本App會處理該等媒體。本版本的上載介面只接受相片；JPG、PNG 或 HEIC 相片會在裝置上轉換及壓縮成 JPEG 後上載。本App目前不支援影片上載，亦不會掃描或上載用戶未選取的相片或影片。
  • 聊天室錄音：當你主動按下錄音按鈕並送出語音訊息，本App會使用咪高峰建立最長兩分鐘的 M4A 錄音。錄音在送出前暫存於裝置；只有你選擇送出的錄音才會上載。本App不會在背景自行錄音。
  • 私人訊息：私人對話的參與者 UID、文字、圖片、語音、雙方媒體同意狀態、封鎖狀態及必要的訊息時間／預覽。文字只供對話參與者使用；圖片及語音必須雙方明確同意後才可傳送或取回。撤回同意或封鎖後不可再上載或取回媒體。
  • 每日朋友配對：你主動加入當日配對時提供的年滿 18 歲確認、性別（男／女）、偏好（男／女／男或女）、當日加入狀態、配對結果及近期配對紀錄。候選池不會向其他用戶公開；每日資格以香港日期計算，翌日不會自動續期。
  • 成就、積分及排行榜：伺服器按合資格社群活動計算活動積分及成就。公開排行榜最多顯示提供排名所需的 UID、顯示名稱、頭像、積分及已解鎖徽章；不會公開朋友配對偏好或私人訊息。
  • 訂閱及購買紀錄：iOS 訂閱由 Apple 處理；我們的 Firebase 後端只保存核實權益所需的 Apple 交易資料、產品識別碼及到期／撤銷狀態。Web 訂閱目前未啟用；日後啟用時 Stripe 會處理付款，我們只會保存 Stripe 客戶對應、訂閱權益及事件收據所需資料，絕不接收或保存完整付款卡資料。
  • 「大學問」文章浮水印：閱讀「大學問」文章時，本App會在裝置上顯示由遮罩後的 Firebase 用戶識別碼、文章 ID 及香港時間組成的浮水印，用於阻嚇未經授權分享。本App不會因而上載或儲存閱讀畫面的截圖。

用戶提交的相片及聊天室錄音會儲存於 Google Firebase Storage。檔案會按隨機 Firebase 用戶識別碼、UGC 類型及相關內容識別碼組織，因此會與該 Firebase 身份及相關內容連結；我們只會為提供相關 UGC 上載、顯示或播放、編輯、刪除及管理功能而處理這些媒體。

自訂個人頭像及個人檔案橫額同樣會上載至 Firebase Storage，並以 Firebase UID 連結的帳戶路徑（例如 ugc/{UID}/avatar/profile/ 或 ugc/{UID}/banner/profile/）儲存。這些圖片用於呈現你的個人檔案及適用的社群、對話、成就或排行榜身份，並按服務功能及存取權限向已登入用戶顯示；它們不是密碼或登入憑證。

本App目前不使用第三方廣告、不進行跨App追蹤，亦不會出售用戶資料。iOS App 使用 Firebase Analytics 記錄有限、預先限定的產品互動事件及非用於追蹤的裝置／App 實例、效能資料，例如曾開啟會員頁或開始訂閱流程；事件參數只限一般類別、來源或類型，不包含貼文、訊息、電郵、Firebase UID 或通知權杖。iOS App 亦使用 Firebase Crashlytics 處理當機報告、堆疊追蹤、裝置／作業系統資料及與當機相關的 App 狀態，用於找出錯誤及改善穩定性。

3. 本機資料儲存

本服務在 iOS 裝置及 PWA 瀏覽器使用本機儲存保存以下資料：

  • 📎 書籤紀錄：用戶收藏嘅文章 ID 列表，方便整理同日後重溫
  • 🎨 外觀偏好：用戶選擇嘅深色/淺色模式設定
  • 📝 未提交草稿：文章草稿只保存在目前裝置，提交前不會上傳
  • 🛡️ 社群偏好：已接受守則、已封鎖用戶及反應去重紀錄
  • 🌐 PWA 本機設定：PWA 的 localStorage 可保存裝置識別碼、已儲存文章 ID、已封鎖作者 ID 及已接受的社群守則／EULA 版本；這些資料留在你的瀏覽器。
  • 🗂️ PWA 草稿：PWA 以 IndexedDB 保存未送出的貼文、提問及留言草稿，並以 UID 或裝置範圍隔離；草稿不等於已發佈內容。
  • 👤 已知帳戶：為方便安全切換帳戶，裝置最多保存八個你曾成功登入帳戶的 Firebase UID、電郵（如有）及顯示名稱；不保存密碼、Firebase refresh token 或其他登入憑證。你可隨時從裝置移除個別已知帳戶紀錄。

PWA 的 service worker 只會快取靜態 App shell 與同源公開圖片，方便基本離線開啟；不會快取「大學問」premium 正文。清除瀏覽器網站資料或移除 App 通常會移除本機資料；已上傳到 Firebase 的內容須使用服務內「刪除帳戶及所有資料」功能刪除。

4. 第三方服務

本App使用以下服務提供核心功能：

  • Google Firebase Authentication：建立及管理匿名訪客身份。
  • Google Cloud Firestore／Cloud Functions：同步社群、個人資料、寫手申請、投稿及已刊文章；在伺服器核實訂閱、管理每日免費文章額度，並按權限提供「大學問」文章正文。
  • Google Firebase Storage：接收、處理及儲存用戶主動選取並提交的 UGC 相片、聊天室錄音、自訂個人頭像及個人檔案橫額，並按 Firebase 用戶識別碼及相關內容／個人檔案類型組織檔案。
  • Google Firebase Analytics／Crashlytics：處理有限的產品互動、非追蹤用途的裝置／App 實例與效能資料，以及當機報告及相關診斷資料，用於分析功能使用情況、偵測錯誤及改善 App 穩定性。
  • Apple StoreKit／App Store：處理訂閱購買、恢復購買及提供由 Apple 簽署的交易資料作權限驗證。
  • Stripe（僅在日後啟用 Web 訂閱時）：處理 PWA 的 Checkout、付款及 Billing Portal。Web checkout 目前保持關閉，因香港商戶設定及所需的四項伺服器端 Stripe secrets 尚未完成。

第三方服務可能按其服務運作需要處理裝置、網絡及診斷資料。詳情請參閱 Firebase 私隱與安全資料及 Apple 私隱政策。

6. 用戶內容（UGC）公開性及授權通知

公開文章、社群貼文、留言、聊天室文字及語音訊息、問題、答案、作者資料及其公開 metadata／相片會向公眾或其他用戶顯示或播放，並可能被分享、搜尋、截圖、錄製或暫存；請勿提交你不希望公開的個人或敏感資料。被隱藏、移除或隔離的內容不會在公開 reader 顯示，但其內容及必要 metadata 可按營運、審核、安全、處理舉報及法律需要由獲授權人士及服務供應商處理。寫手申請、未刊投稿、舉報及審核資料同樣不屬公開內容。

私人訊息並非公開聊天室。私人訊息文字及媒體只供該對話參與者使用。Firebase Storage 不接受用戶端直接讀寫私人媒體；媒體由已驗證的伺服器功能在每次上載或取回時重新核對雙方成員身份、同意、封鎖、帳戶狀態及個別檔案的審核撤銷紀錄。管理員不會任意瀏覽私人對話；只有收到指定訊息的舉報後，具現行管理權限而未被停用的審核員才可按該舉報取用相關訊息或媒體證據。

你保留對 UGC 原有的權利。當你提交、上載或發佈 UGC，你確認擁有內容或已取得所需權利，並在適用法例容許的最大範圍內，授予本App營運者一項非獨家、全球性、免版稅、可轉讓及可再授權的許可。在該許可下，UGC 會成為本App可合法取用及運用的內容資產；我們可託管、儲存、備份、複製、轉換格式、翻譯、改編、發佈、公開展示、傳送、分發及以其他方式使用內容，以營運、維護、改善、推廣及保障本App與相關服務、處理舉報及履行法律責任。

此許可不會把 UGC 的所有權轉移給我們，也不容許我們在上述目的或適用法例以外任意使用內容。完整條款、保證及責任限制請參閱使用條款。

7. 保存及刪除

雲端資料會保存至提供相關功能所需的期間。用戶可在 iOS App 或 PWA「設定 → 刪除帳戶及資料」永久刪除其 Firebase 身份、個人資料、社群內容、留言、投稿、已刊文章、寫手申請及舉報資料。操作不能還原。

帳戶刪除亦會清除或匿名化可歸屬該帳戶的朋友配對設定、每日配對／配對紀錄、封鎖、成就、排行榜及活動積分私人紀錄，以及私人對話成員關係、訊息正文與已上載私人媒體。現行及歷史的內容隔離紀錄與審核稽核紀錄如可歸屬該帳戶（包括帳戶是管理員、舉報者、內容作者或私人對話參與者），會在原始舉報、內容及對話成員資料仍可核對時清除或不可逆匿名化。現行隨機識別碼紀錄只可覆寫成固定匿名標記，標記不含 Firebase UID、正文、電郵、顯示名稱、媒體路徑、內容／舉報／對話識別碼、審核動作或時間；無法確認識別碼不含身份的舊紀錄會整項刪除。為處理安全事故、法律要求或防止重建資料，刪除鎖及本節另述的最低限度墓碑仍可按所述用途保留。

上載至 Firebase Storage 的 UGC 相片及聊天室錄音一般會保留至用戶移除相關媒體、刪除相關內容或使用「刪除帳戶及所有資料」功能。社群媒體不由用戶端直接刪除；後端會建立不遺失的清理紀錄及短暫刪除租約，重新核對現行內容沒有引用該檔案後才由伺服器刪除。租約生效期間不得重新掛接該媒體；如發現仍有有效引用，清理會停止並保留檔案。即使實體檔案因暫時故障尚未清除，媒體擁有者一經建立永久 UID 刪除墓碑，Firebase Storage 規則亦會拒絕已知連結的讀取。

自訂個人頭像及個人檔案橫額一般保留至你更換或移除圖片、刪除帳戶，或服務不再需要提供個人檔案功能。更換或移除後，系統會刪除不再由帳戶個人檔案引用的舊檔；帳戶刪除流程亦會清理 UID 路徑下的相關圖片。已由其他用戶保存的截圖或副本不受我們控制。

刪除後，為防止濫用、履行法律責任、處理爭議或維持備份完整性所需的有限紀錄，可能在合理期間內保留；其他用戶已合法取得的副本、分享或截圖亦未必可由我們控制或刪除。

刪除本App帳戶時，我們會刪除與該 Firebase 身份連結的伺服器端訂閱驗證及每日解鎖紀錄。刪除程序使用兩種用途不同的最低限度安全紀錄：(一)短暫的操作鎖，包含 Firebase UID、刪除操作識別碼、建立／更新／到期時間及格式版本，用於協調重試與處理競態；首次到期時間通常為 24 小時後，每次重試可延長而不會縮短原有到期時間，雲端自動清理可在到期後稍後完成；以及 (二)不設到期日的 UID 刪除墓碑，只包含 Firebase UID、首次刪除操作識別碼、建立／更新時間及格式版本，永久保留，唯一用途是阻止同一已刪除 UID、舊登入憑證或延遲事件重新建立帳戶或社群資料。UID 刪除墓碑不包含個人檔案、訊息、配對偏好、媒體、密碼或登入 token，亦不會用於宣傳、個人化或建立公開個人資料。另有不含原始 Firebase UID 的 SHA-256 購買安全標記按付款安全需要保留。Apple 管理的購買及訂閱紀錄受 Apple 的保存政策規管，並不會因刪除本App帳戶而從 Apple 帳戶移除。

如日後你有有效的 Web 訂閱，帳戶刪除流程會先在 Stripe 取消並刪除該客戶資料，再清除本服務的本機及 Firebase 資料。取消在刪除時即時生效，並不自動退款；這與你在 Stripe Billing Portal 正常取消（停止續期、已付款期間仍可使用）不同。
