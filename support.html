PWA 安裝及登入

  1. 以支援 PWA 的瀏覽器開啟網站；如瀏覽器顯示「安裝」或「加入主畫面」，按指示完成。
  2. 純閱讀、在目前裝置收藏文章及使用每日免費閱讀額毋須登入；系統可建立匿名 UID，把相關紀錄與目前訪客身份連結。
  3. 發帖、留言、提問、回答、使用聊天室、舉報或上載相片／錄音前，必須先註冊帳戶並完成電郵驗證。
  4. 要在同一身份上保留資料，可在帳戶頁用 Email Link 升級；升級保留現有 UID，但不會把兩個既有帳戶自動合併。

PWA 草稿只保存在該瀏覽器的 IndexedDB；清除瀏覽器網站資料或使用另一部裝置前，請先完成或另行備份草稿。

iOS App 訂閱及恢復購買

  1. 在App內打開「高級大人會員」頁面。
  2. 選擇月費或年費方案，或點按「恢復購買」。
  3. 如需取消或管理訂閱，請前往 iPhone「設定」→ Apple 帳戶 →「訂閱項目」。

付款、續期及退款由 Apple App Store 處理。刪除 App 或 App 內帳戶不會自動取消 Apple 訂閱。香港 iOS App 不提供 Web 購買連結或 CTA。

Web 訂閱（目前未啟用）

Web checkout 目前保持關閉，因香港 Stripe 商戶設定及四項伺服器端 secrets 尚未完成；現時不可在 PWA 購買，Apple Pay 亦未有提供。日後啟用後，Web 月費為 HKD 28、年費為 HKD 198。Stripe Checkout／Billing Portal 可在支援的裝置和瀏覽器提供 Apple Pay 等可用付款方式；請只在 PWA 的「會員及付款」管理 Web 訂閱。

日後正常在 Stripe Billing Portal 取消，會停止續期而保留至已付款期結束。刪除有有效 Web 訂閱的帳戶則會即時取消並刪除 Stripe 客戶資料，不會自動退款。Web 訂閱與 Apple App Store 訂閱分開管理；現有 iOS 匿名 UID 不會自動連結至首次 Web checkout。

社群內容、舉報及封鎖

所有社群發帖、留言、提問、回答、聊天室訊息、舉報及媒體上載，只供已註冊並完成電郵驗證的帳戶使用。

如發現不當貼文或留言，可在內容選單選擇「舉報」或「封鎖用戶」。我們會按社群守則及適用法例審核。緊急或危及人身安全的情況，請直接聯絡相關緊急服務。

如你的社群發佈權限被停用並希望提出覆核，請電郵聯絡我們，並提供 iOS App 或 PWA 顯示的用戶 UID；停用期間仍可刪除自己的內容或整個帳戶。被隱藏或隔離的內容不會公開顯示，會按社群守則處理。

刪除帳戶及資料

在 iOS App「我的」→「資料與帳戶」或 PWA「設定」→「刪除帳戶及資料」，即可永久刪除 Firebase 身份及相關雲端資料。操作不能還原；Apple 管理的訂閱及購買紀錄不會一併刪除。若日後有有效 Web 訂閱，刪帳會先即時取消並刪除 Stripe 客戶資料，並不自動退款。
